Comecei a construir esse site com [Astro](https://astro.build), usando content collections
para os changelogs e para a listagem de projetos — tudo em Markdown, sem backend, sem CMS.

## O que já está funcionando

- Página inicial com resumo sobre mim e destaque de projetos.
- Listagem de projetos.
- Esse changelog, com categorias e feed RSS.
- Deploy automatizado via GitHub Actions para o GitHub Pages, usando o domínio
  `manuelzzz.dev.br`.

## Próximos passos

- Preencher experiências profissionais e projetos reais.
- Ajustar a paleta e a tipografia conforme for usando o site no dia a dia.
